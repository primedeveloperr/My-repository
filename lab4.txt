1. Як створити новий репозиторій?

Увійти на github.com під своїм обліковим записом, натиснути кнопку «+» у верхньому правому куті та вибрати New repository. Вказати назву репозиторію та короткий опис, вибрати Public, поставити галочку Add a README file і натиснути Create repository.

2. Для чого призначен репозиторій?

Репозиторій — це контейнер для зберігання файлів проєкту разом з історією їх змін. Він дозволяє повертатися до попередніх версій файлів, працювати над проєктом разом з іншими розробниками та зберігати код в мережі Інтернет.

3. Як створити нову гілку у репозиторії?

На сторінці репозиторію натиснути на кнопку з назвою поточної гілки, у полі ввести ім'я нової гілки та вибрати Create branch. Нова гілка є копією основної, і зміни в ній не впливають на основну гілку, доки їх не буде злито.

4. Як злити гілки з основною гілкою master?

Відкрити вкладку Pull requests і натиснути New pull request. Вибрати основну гілку та гілку зі змінами. Коли з'явиться повідомлення Able to merge, натиснути Create pull request, потім Merge pull request і Confirm merge. Після злиття гілку можна видалити кнопкою Delete branch або залишити.

5. Як завантажити репозиторій до себе на комп'ютер?

На сторінці репозиторію натиснути зелену кнопку Code та вибрати Download ZIP. Після завантаження архів потрібно розпакувати. Також репозиторій можна клонувати командою git clone.
